# Naftiko

> Naftiko builds spec-driven integration software for AI agents. Its two Apache 2.0 engines — Ikanos, a capability engine, and Polychro, a polyglot spec linter — let a team declare a slice of its business in one YAML file and serve it simultaneously as MCP, Agent Skill, REST and a Control port, with no code written or compiled. Naftiko operates no hosted API of its own: it distributes software you run, so this profile catalogs a specification, a container image, a CLI and a set of registries rather than endpoints and keys.

This file was GENERATED by API Evangelist from the artifacts in this repository. Naftiko
publishes no llms.txt of its own: https://naftiko.io/llms.txt returns 404, and
https://shipyard.naftiko.io/llms.txt returns a 200 that is the docs single-page-app shell,
not a document.

## What Naftiko ships

- [Ikanos](https://ikanos.io): the capability engine. Reads one capability YAML and exposes it over MCP, Skill, REST and Control simultaneously. Apache 2.0, Java 21.
- [Polychro](https://polychro.io): a polyglot spec linter. Lints YAML, JSON, XML, Markdown and HTML through a composable pipeline; emits SARIF, JSON, text or LLM-native output.
- [Fleet](https://shipyard.naftiko.io/fleet/): Warden (Backstage scaffolding and cataloging) and Skipper (a Kubernetes operator). Enterprise edition, design partners, targeted H2 2026.
- [Crafter](https://naftiko.io/platform/crafter/): a capability builder extension for VS Code and AI IDEs.

## Specifications

- [Ikanos Capability JSON Schema](json-schema/naftiko-ikanos-capability-schema.json): JSON Schema 2020-12, 7 root properties (ikanos, info, consumes, exposes, aggregates, binds, capability) and 86 $defs. The source of truth for a capability document. Note the declared $id, https://ikanos.io/schemas/v1.0.0-beta2/ikanos.json, does not resolve — the schema is retrievable only from the GitHub source tree.
- [Ikanos governance ruleset](rules/naftiko-ikanos-ruleset.yml): 33 first-party rules (14 error, 16 warn, 3 info) in Spectral rule shape, enforced by Polychro at validation, in CI, and at Kubernetes admission with Skipper.
- [Glossary / vocabulary](vocabulary/naftiko-vocabulary.yml): 32 published terms across Core Concepts, Governance, and Protocols & Standards.

## APIs

Naftiko publishes no OpenAPI, no AsyncAPI, no GraphQL schema and no hosted API. The
following surfaces exist and are documented, but none is a Naftiko-operated endpoint an
agent can call:

- Control port: GET /health/live, /health/ready, /status, /metrics, /traces, /scripting on a running capability, default localhost:9090. Specified in the CLI reference; no OpenAPI published. See [conventions](conventions/naftiko-conventions.yml).
- MCP: generated from your capability YAML and served from your infrastructure. Naftiko runs no hosted MCP endpoint. See [mcp](mcp/naftiko-mcp.yml).
- Skill Server: GET /skills/<skill> and /skills/<skill>/download, default localhost:9700. See [skills](skills/_index.yml).
- Mocks: https://mocks.naftiko.net serves 136 third-party API mocks via Microcks, but returns 401 on every path. See [sandbox](sandbox/naftiko-sandbox.yml).

- [Packages](packages/naftiko-packages.yml): 8 first-party distributions — Maven Central (io.ikanos, io.polychro), GHCR + Docker Hub container images, native CLI binaries, and a VS Code extension. All at 1.0.0-beta4, published 2026-08-17.
- [CLI](cli/naftiko-cli.yml): the `ikanos` command surface — create, validate, import openapi, export openapi, serve, health, status, metrics, traces, scripting — plus exit codes and environment variables.
- [Plans and pricing](plans/naftiko-plans-pricing.yml): four editions (Community, Developer, Team, Enterprise). No monetary price is published for any of them; Community is free forever, two are in development, Enterprise is design-partners.
- [Rate limits](rate-limits/naftiko-rate-limits.yml): none published, and none applicable — the software runs on your infrastructure.
- [Lifecycle](lifecycle/naftiko-lifecycle.yml): semver-with-prerelease, per-version EOL dates in a public release table, versioned docs trees, an itemized roadmap. No status page, no SLA, no Sunset/Deprecation headers.
- [Changelog](changelog/naftiko-changelog.yml): GitHub Releases plus a docs release table carrying EOL date, Java baseline and Maven groupId per version.
- [Conformance](conformance/naftiko-conformance.yml): what the engine genuinely implements (JSON Schema 2020-12, OpenAPI import/export, MCP, Agent Skills, OAuth 2.1, OpenTelemetry, Prometheus) versus what is named but not shipped (A2A, AsyncAPI, gRPC, JSON Structure).
- [Conventions](conventions/naftiko-conventions.yml): the semantics of the specification, the control port, and the observability surface.
- [Sandbox](sandbox/naftiko-sandbox.yml): the mock-service programme — 136 third-party specs and 25 one-click-deployable sandbox capabilities.
- [Skills](skills/_index.yml): three verbatim provider-published agent instruction files.
- [Well-known](well-known/naftiko-well-known.yml): a recorded absence — zero documents across every host.
- [Domain security](security/naftiko-domain-security.yml): TLS 1.3, SPF and DMARC p=reject on naftiko.io; no HSTS, no DNSSEC, no CAA.
